# なぜ BEAR.Sunday か

10年間、後方互換を破らない PHP フレームワーク。
1つのリソースが API にも、サイトにも、CLI にもなる。
作ったものは資産として残る。

---

## 長期的価値

- **後方互換10年**: 破壊的変更ゼロ、移行コスト不要
- **資産性**: リソース/SQLは他システムでも再利用可能
- **標準準拠**: 独自規格なし、業界標準に依拠

## 品質と信頼性

- **パフォーマンス**: 起動コスト最小、高速応答
- **高可用性**: CDN統合、イベント駆動キャッシュ、SPOF回避
- **型安全**: 静的解析最高レベル、テストカバレッジ100%

## 開発効率

- **統一インターフェース**: 1リソース = Web + API + CLI
- **ドキュメント自動生成**: JsonSchema駆動
- **開発者体験**: リソース状態可視化、リアルタイム編集

## 柔軟性と拡張性

- **段階的導入**: 既存システムからの漸進的移行
- **多言語接続**: Thrift / HTTP / Composer連携
- **ライブラリ非同梱**: 技術選択の自由

## 透明性とチーム開発

- **明示的設計**: 宣言的、設定ファイル不要
- **AI理解**: llms.txt対応、構造化リソース
- **チームスケール**: 一貫した制約で認知負荷減
